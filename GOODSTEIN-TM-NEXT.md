## The machine (read `tools/goodstein_tm/README.md` and `build_halt.py` first)

The tape is `bb…b [ ] P d^k₁ P d^k₂ …`: the base in unary, then the tree as a level sequence, each
node `P` followed by its depth in unary.  Each loop iteration of the core is **one Kirby–Paris hydra
move with `n = b − 1` copies** on the level sequence `t`:

- delete the last node `L` (always a leaf), at depth `k`;
- if `k = 1`: the Goodstein step is done.  Bump the base (`GSTEP_BUMP` writes one more `b`), or
  halt if the tree is empty (`STEP_DONE_CHECK2` reading `]` is the only reachable halt);
- else let `X` be the nearest node left of `L` with depth `k − 1` (`L`'s parent).  Append `n` copies
  of the block from `X` to the end of the tape (`X`'s pruned subtree).  These become siblings of `X`.

Marks used along the way: `T` the last node's `P`, `C` the candidate parent's `P`, `D` a compared
`d`, `S`/`z` the start/end of the block to copy, `s p e y` already-copied cells, `B` a used base
counter (restored to `b` by `REP_DONE`).  States with `BACK_` prefixes are stay-moves split into
right-then-left.

## Route

1. **Hydra (`Hydra.lean`).**  Define `chop (n : ℕ) (t : List ℕ) : List ℕ` for the move above, with
   `t = s ++ [k]` and the block `s.drop i` where `i` is the last index with `s[i] = k − 1`.  Prove
   `WF` is preserved.  Give the termination measure: an ordinal (`ord t = ` a sum of `ω ^ ord(child)`
   over the top-level subtrees, best as a natural sum, see `Ordinal.nadd`/`NatOrdinal`), or a nested
   multiset under the Dershowitz–Manna order if Mathlib has it.  Prove the measure strictly decreases
   for every `n` and every nonempty `WF t`.  Sanity-check `chop` with `decide` against small
   examples from `tools/goodstein_tm/check.py` (`sub1` is the full step: repeat `chop` until a depth-1
   node is deleted).
2. **Tape encoding (`Sim.lean`).**  Define the configuration for base `b` and tree `t` at the start
   of a chop (state `GO_CHOP` or `CHOP_START`, choose the cleanest).  Trailing blanks: state every
   lemma for an arbitrary tail `List.replicate j .blank`, since `headD` of `[]` and of `blank :: _`
   agree.
3. **Segment lemmas.**  One generic lemma for scan states: a scan state over a run of symbols it
   passes moves through the run in `length` steps.  Then one lemma per loop: `CHOP_FINDL`, the
   compare loop `CAND_FIND/CMP_*/NOTPARENT` (finds the parent), `ERASE_L/MARK_END/UNMARK_S`, the copy
   loop `CP_SCAN/CARRY_*/CP_RET` (by induction on the block length), and the replicate loop
   `REP_*/GO_S/CP_END/CP_UNM/REP_RET` (by induction on the remaining unmarked `b`s), then `REP_DONE`
   and `RD_S/RD_Z`.
4. **Macro step.**  From the chop configuration with base `b` and nonempty `t`: the machine reaches
   the chop configuration for `chop (b − 1) t` (last depth > 1), or for base `b + 1` (last depth 1,
   tree nonempty), or halts (tree empty).
5. **Init.**  `stepN (cellsOf t).length start` reaches the configuration entering `GSTEP_BUMP`
   (induction over the cells).
6. **Headline.**  Well-founded induction on the measure of `t`, generalizing over `b`.
